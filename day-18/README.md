# HTML Webpage

A simple webpage created using HTML5 to practice the structure and commonly used HTML elements.

## 📌 About

This project is a basic HTML webpage that demonstrates how to structure a complete webpage using semantic HTML elements.

The webpage includes a header/navigation bar, hero section, article section, table, embedded video, contact form, and footer.

## ✨ Features

- Header and navigation bar
- Hero section
- Article section
- HTML table
- Embedded YouTube video
- Contact form
- Footer

## 🛠️ Technologies Used

- HTML5
